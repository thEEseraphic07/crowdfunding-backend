CrowdFund Backend is the server-side application powering CrowdFund, a crowdfunding web application that enables users to create campaigns, receive donations, and manage fundraising activities.

Built with Node.js, Express.js, and MongoDB, the backend provides RESTful APIs for authentication, campaign management, donations, payment processing with Paystack, email verification, password recovery, and administrative controls.

The application also includes role-based access control, campaign approval workflows, wallet management, withdrawal requests, and email notifications.

Tech Stack: Node.js · Express.js · MongoDB · PayStack · Socket.IO · Resend

Status: Actively developed and deployed on Render.
